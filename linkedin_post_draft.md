# LinkedIn Post — Assignment 4: Human Activity Recognition

We recently completed an Applied Machine Learning project focused on **Human Activity Recognition (HAR)** using smartphone motion sensors.

Our goal was to classify six human activities from raw accelerometer and gyroscope time-series data using PyTorch.

### What we implemented
- Raw sensor data preprocessing
- Subject-wise training, validation, and testing
- Custom RNN and LSTM components
- Bidirectional LSTM architecture
- Temporal Attention mechanism
- Model training and evaluation
- Confusion matrix and per-class analysis
- Attention visualization
- Interactive Streamlit demonstration

### Results
Our model achieved **93.45% test accuracy** on the UCI HAR dataset.

The model performed particularly well on walking-related activities and laying, while sitting and standing remained more challenging due to similarities in their sensor patterns.

This project helped us understand sequence modeling, recurrent neural networks, attention mechanisms, model evaluation, and the importance of analyzing errors rather than focusing only on accuracy.
